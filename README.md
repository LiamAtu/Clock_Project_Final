# Analog Clock Project

An analog clock built with HTML, CSS and JavaScript. No dependencies — just open `index.html` in a browser with no FrameWorks.I did this project speciffically for IT Professional Skills Assignment

## Files

- `index.html` — clock structure
- `style.css` — styling
- `logic.js` — live time updates and tick mark generation
